# Week 1 · October DSA (Oct 1 – Oct 7)

| Day | Primary problem | Topic |
|---|---|---|
| 1 | Two Sum | Hashmap lookup |
| 2 | Contains Duplicate | Set membership |
| 3 | Single Number | XOR / bit trick |
| 4 | Running Sum of 1d Array | Prefix sum intro |
| 5 | Majority Element | Hashmap counting + Boyer-Moore |
| 6 | Find All Numbers Disappeared in an Array | In-place marking |
| 7 | Intersection of Two Arrays II | Hashmap counting + multiset |

Each day folder has one `.py` file per problem (`01_` is always the primary, the rest are variants) and a `README.md` with brute force, optimal approach, complexity and the matching LeetCode / GFG questions.

**Run any file:** `python3 "Day 1 - Two Sum/01_two_sum.py"` — every file has small test cases at the bottom.

**No-libraries rule:** zero imports anywhere. No `sorted()` / `.sort()` either — problems that need sorting use a hand-written `merge_sort`.
